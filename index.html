SYNCRA

Logic Pro の曲を、仲間と一緒に仕上げる。Mac の音を iPhone・iPad で聴きながら、その場で確認・相談できる共同制作アプリ。

Mac 版をダウンロード

iPhone・iPad 版（App Store で公開予定）

できること

Logic の音を iPhone・iPad で聴く
Mac の Logic Pro に挿す「SYNCRA Monitor」から、同じ Wi-Fi の iPhone・iPad へ音を送ります（圧縮しない 32bit float）。波形を見ながら聴きたい所へ移動できます。
ループとソロ
波形をなぞってループを決め、A・B・C に覚えて呼び出し。トラックのソロも iPhone・iPad から切り替えられます。
気になった所に、その場でメモ
聴いている位置に共有メモを追加。メモの位置を押すと、Mac の Logic の再生ヘッドがそこへ移動します。
メンバーと相談
メッセージ・共有メモ（チェックリスト）・写真や動画の添付で、「直す所」を共有できます。

はじめかた

  1. Mac 版 SYNCRA をダウンロードして、「アプリケーション」フォルダへ移動します。
  2. SYNCRA を開き、アカウントを作ります（Apple でサインイン、またはメール）。
  3. Logic Pro の Stereo Out に「SYNCRA Monitor」を挿します。
  4. iPhone・iPad の SYNCRA を開き、Mac に表示される QR コードまたは 6 桁のコードでペアリングします。
  5. Mac 版の有料プランは、アプリの中で購入します（決済は Paddle が行います）。
