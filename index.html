The experience

曲の確認に、
新しい流れを。

Mac の前に集まらなくても、同じ音を聴きながら、同じ所を指して話せる。SYNCRA が目指すのは、修正の相談がその場で進む制作の時間です。

01 / Listen

Logic の音を、手元で聴く

Logic Pro の Stereo Out に挿した「SYNCRA Monitor」から、同じ Wi-Fi の iPhone・iPad へ、圧縮しない 32bit float で音が届きます。全体の波形から聴きたい所へ移動。10 秒の前後移動、LIVE への復帰もワンタップ。ステレオ／モノ／左／右の切り替えと遅延の表示に対応。

♪
⟲
02 / Loop

ループを 3 つ覚える

波形をなぞるだけでループの範囲が決まります。A・B・C に覚えて、押すだけで呼び出し。Logic のサイクルと連動するので、Mac を触らずに同じ所を繰り返し聴けます。

Good to know

よくある質問

SYNCRA はどんなアプリですか？

Mac の Logic Pro で作っている曲を、iPhone・iPad で聴きながら、仲間と確認・修正できる共同制作アプリです。

iPhone・iPad だけで使えますか？

音を聴くには、Mac 版 SYNCRA（macOS 14 以降）と Logic Pro が必要です。iPhone・iPad だけでは音は聴けません。

iPhone・iPad で音が聴こえません

Logic の Stereo Out に「SYNCRA Monitor」を挿してあるか確認してください。Mac と iPhone・iPad を同じ Wi-Fi につなぎ、iPhone・iPad の「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で SYNCRA をオンにしてください。

無料体験は自動で有料になりますか？

なりません。7 日間・1 人 1 回・保存 1GB までです。有料プランを契約しなかった場合、体験中のクラウド上のプロジェクトは終了から 30 日後に削除します。

解約・返金は？

解約すると次回以降の更新の課金が止まります。iPhone・iPad の App 内課金は「設定」→ 自分の名前 →「サブスクリプション」から。返金は返金の方針をご覧ください。

アカウントを削除したい

アプリの「設定」→「アカウントを削除」から行えます。
