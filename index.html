Logic Pro × iPhone・iPad

Logic の曲を、
みんなで仕上げる。

Mac の Logic Pro の音を、同じ Wi-Fi の iPhone・iPad でリアルタイムに聴ける。ループ・ソロ・位置つきの共有メモもリアルタイムに共有され、確認と修正の相談がその場で進みます。

SYNCRA は、Mac の Logic Pro と iPhone・iPad をつなぐ、音楽の共同制作アプリです。

できること

曲の確認に、新しい流れを。

Mac の前に集まらなくても、同じ音を聴きながら、同じ所を指して話せる。修正の相談が、その場で進みます。

Logic の音を iPhone・iPad で聴く

Logic Pro に挿す「SYNCRA Monitor」から、同じ Wi-Fi の iPhone・iPad へ、圧縮しない 32bit float で音を送ります。曲全体の波形を見ながら聴きたい所へ移動。10 秒の前後移動、LIVE への復帰もワンタップ。ステレオ／モノ／左／右の切り替えと、遅延の表示に対応。

ループを 3 つ覚える

波形をなぞるだけでループの範囲を決められます。A・B・C に覚えて、押すだけで呼び出し。Logic のサイクルと連動するので、Mac を触らずに繰り返し聴けます。

トラックをソロで聴く

iPhone・iPad からトラックのソロを切り替え。ソロ中のトラックは色分けした波形で重ねて表示します。

気になった所に、その場で共有メモ

聴いている位置に共有メモをワンタップで追加。小節・拍でも、分・秒でも指定できます。メモやメッセージの位置を押すと、Mac の Logic の再生ヘッドがそこへ移動します。

メンバーと相談

プロジェクトのメンバーとメッセージ・共有メモでやり取り。写真や動画も添付できます。共有メモはチェックリストにでき、「直す所」の確認漏れを防げます。メンバーのオンライン・再生位置もひと目で分かります。

7 か国語に対応

日本語・英語・ドイツ語・フランス語・スペイン語・韓国語・ポルトガル語（ブラジル）。Logic Pro の各言語の用語に合わせています。

使い方

実際の画面で、すべての機能の使い方

上の流れる帯の項目を押しても、その使い方に飛べます。

01

Logic に SYNCRA Monitor を挿す

  1. Logic Pro の Stereo Out の Audio FX に「SYNCRA Monitor」を挿します。
  2. 「待機中」と出れば準備完了。iPhone・iPad で SYNCRA を開くと、同じ Wi-Fi の中で自動でつながり、Logic の音がリアルタイムで届きます（初めての iPhone のときだけ、ここに番号が出ます）。
  3. 音声パスは「パススルー（音声変化なし）」。入力の音を 1 サンプルも変えずに Logic へ返し、iPhone へは同じ音を送ります。サンプルレートとビット深度（32bit Float）も表示されます。

音は同じ Wi-Fi の中だけで送ります（インターネットには出しません）。

画面の各部

  1. 接続状況待機中・接続中などの状態と、つながっている iPhone・iPad の台数。
  2. 送信の状態iPhone・iPad へ音を送っているか（送信中／送信待ち）。つながると自動で送ります。
  3. 音声の形式サンプルレート・ビット深度（32bit Float）と、通信の往復時間。
  4. iPhone と接続初めての iPhone のときだけ、ここと iPhone に同じ 6 桁の番号が出ます。同じなら「一致」を押します。
  5. 送信レベルこの AU に届いた音の左右のメーター。
  6. 音声パスパススルー。入力の音を 1 サンプルも変えずに Logic へ返します。
  7. 保存して送る前面の共同プロジェクトの曲の変更を、ここからも保存して送れます。
  8. 同じ Wi-Fi の中だけ音は同じ Wi-Fi の中だけで送り、インターネットには出しません。
もっと詳しく（アプリ内の使い方）
Mac の準備
  1. SYNCRA を起動したままにします。
  2. Logic の Stereo Out のチャンネルストリップに、プラグイン「SYNCRA Monitor」を挿します（オーディオ FX の枠から、「Audio Units」の中の「SYNCRA」を選びます）。
  3. macOS に「ローカルネットワーク」の許可を求められたら、許可してください（インターネットには送りません）。

SYNCRA Monitor は、音を一切変えません。入力された音を、そのまま Logic に返します。

iPhone でつなぐ
  1. iPhone の SYNCRA で、「モニター」タブを開きます。同じ Wi-Fi の Mac を、自動で見つけてつなぎます。
  2. 初めての Mac のときだけ、iPhone と Mac の SYNCRA Monitor の画面に、同じ 6 桁の番号が出ます。同じなら、Mac の画面で「一致」を押してください。違うときは「一致しない」を押します。
  3. 2 回目からは、番号なしで自動でつながります。
Mac の画面で確認できること
  • 「接続状況」: 待機中・接続中などの状態。
  • 「送信状態」: iPhone へ送信中かどうか。
  • 「iPhone と接続」: 接続中の iPhone と、「切断」ボタン。
  • 「送信レベル」: 届いた音の左右のメーター。

iPhone からの再生・停止・移動・ループ・全体の波形の書き出しは、Mac の SYNCRA が起動していて、アクセシビリティが許可されていることが必要です。波形を書き出している間は、Logic が前面に出て操作されます。Mac で別の作業をしているときは、気をつけてください。

02

Logic プロジェクトを登録する

  1. 「プロジェクト」を開き、「Logic プロジェクトを追加」を押します。Finder から .logicx をドラッグしても追加できます。
  2. 登録すると、場所・録音フォルダ（Media/Audio Files）の検出・登録日・最後に開いた日時が表示されます。
  3. 「Logic で開く」で Logic が起動します。「メンバーを追加」から、すぐにメンバーを招待できます。

「登録を解除」は SYNCRA から外すだけで、Logic のプロジェクト自体は消えません。

画面の各部

  1. 左の一覧プロジェクト・保存して送る・メンバー・アカウント・履歴・設定を切り替えます。
  2. 常駐パネルを開くLogic の横に置く小さな状態パネル（SYNCRA ステータス）を開きます。
  3. 登録した曲のカード状態（アクセス可能／要更新／アクセス不可）。「開く」で Logic で開き、✕ で一覧から外します（ファイルは残ります）。
  4. 曲を登録するFinder から .logicx を点線の枠へドラッグするか、「Logic プロジェクトを追加」（⌘N）で選びます。
  5. メンバーを追加この曲にメンバーを招待します（QR コード・招待コード・SYNCRA ID）。
  6. 7 つのタブ情報・メッセージ・チェックリスト・やり取り・更新履歴・共有メモ・メンバー。新着は赤い数字で出ます。
  7. プロジェクト情報場所・録音フォルダ（Media/Audio Files）・登録日・最後に開いた日時・共同プロジェクトの接続。
  8. 操作ボタン常駐パネルを開く・Logic で開く・登録を解除（Logic のファイルは消えません）。
  9. この画面の使い方どの画面でも、右上からその画面の手順を見られます。
もっと詳しく（アプリ内の使い方）
登録のしかた（2 通り）
  1. 左の一覧の「プロジェクト」を開きます。
  2. 方法 A: Finder から .logicx を、画面の点線の枠へドラッグします（複数を同時にドラッグできます）。
  3. 方法 B: 「Logicプロジェクトを追加」（⌘N）を押し、ファイルを選んで「登録」を押します。

登録するのは、ファイルの場所だけです。Logic のファイル自体は、そのまま残ります。

カードの見方と操作
  • 状態は 3 種類です。「アクセス可能」は問題なし。「要更新」は場所が変わった可能性があります。「アクセス不可」は、場所を選び直す必要があります。
  • カード右下の「開く」で、Logic でその曲を開きます。いま Logic で開いている別の曲は閉じられます。保存していない作業があれば、Logic が確認します。
  • カード右上の ✕ で、この Mac の一覧から外します。Logic のファイル、サーバー上の共同プロジェクト、メンバーはそのまま残ります。
右側の 7 つのタブ
  • 「情報」: 場所・録音フォルダ・登録日などの確認と、「Logicで開く」「登録を解除」。
  • 「メッセージ」「チェックリスト」「やり取り」「更新履歴」「共有メモ」「メンバー」: 以降のページで説明します。
  • 「メッセージ」「やり取り」「共有メモ」「メンバー」のタブには、新着の数が赤い丸数字で出ます。
うまくいかないとき
  • 「このプロジェクトは既に登録されています」: 同じ曲は 2 回登録できません。
  • 「Logic Pro プロジェクト（.logicx）を選択してください」: フォルダではなく .logicx を選んでください。
  • 「アクセス不可」: 「情報」タブの「場所を再選択」で選び直すと直ります。
03

常駐パネルで、メンバーの状態をリアルタイムに

  1. 「常駐パネル（ステータス）を開く」で、小さな状態ウインドウが開きます。
  2. サーバーへの接続状態と、メンバーのオンライン／オフラインが一覧で見られます。自分の状態もリアルタイムでメンバーへ共有されます。
  3. 「録音フォルダを監視中」の間は、Logic で録音を始めると自動で「録音中」になります。「録音を選んで共有…」で録音も送れます。

Logic の作業を邪魔しないよう、パネルの表示サイズは「設定」で変えられます。

画面の各部

  1. 接続の状態サーバーにつながり、自分の状態をメンバーと共有しているか。
  2. メンバー名前・@ID・役割と、状態（オンライン・録音中・編集中・同期中・オフライン）。
  3. 状態の表示相手が編集中・録音中のときは黄色の注意が出ます。
  4. 録音フォルダの監視Logic で録音を始めると、自動で「録音中」になります。
  5. 録音を選んで共有録音を選んでメンバーに送ります。録音が終わると「このテイクを共有」も出ます。
  6. ドラッグで送るLogic のリージョンやプロジェクト（.logicx）を送り先の枠へドラッグ。録音位置の情報つきで送られます。
もっと詳しく（アプリ内の使い方）
開く
  1. 「プロジェクト」画面の「常駐パネル（ステータス）を開く」を押します。
  2. 「情報」タブの「常駐パネルを開く」や、「設定」の同じボタンからも開けます。
  3. パネルは、Logic よりも手前に表示され、位置とサイズは覚えられます。
見られるもの
  • 「メンバー」: 名前・@ID・役割・状態（「オンライン」「録音中」「編集中」「同期中」「オフライン」）。相手が編集中・録音中のときは、黄色の注意が出ます。
  • 録音フォルダの監視: 「録音フォルダを監視中」「録音中を検出」などの状態。
  • 「メッセージ」: 直近の 5 件と入力欄。
  • 「届いた音」: メンバーが送った音。ダブルクリックで、Logic の録音位置に置けます。
録音を共有する
  1. 録音が終わると、「このテイクを共有」が出ます。押すと共有されます。
  2. 「録音を選んで共有…」で、ほかの録音を選んで共有することもできます。
  3. Logic のリージョンを、パネルの送り先の枠へドラッグしても送れます（録音位置の情報つきで送られます）。
  4. 途中で止まった送信は、「再開」で続けられます。
自動同期のスイッチ（プロジェクト全体）
  • 「Logic で保存（⌘S）したら自動で送る」
  • 「メンバーの新しい版を自動で受け取る」
  • 「録音が終わったら保存して送る」
  • 「変更・録音のたびに「保存して送るか」を聞く」
  • 「開いている曲も新しい版に開き直す」（保存していない作業があるときは待ちます）

スイッチは、初期はすべてオンです。

04

メッセージで、位置つきで相談

  1. 「メッセージ」タブを開き、下の欄にメッセージを書いて送ります。
  2. 「位置（任意）」に小節・拍、または分・秒を入れると、位置つきで届きます。
  3. メッセージの「▶ 小節・拍」を押すと、Logic の再生ヘッドがそこへ移動します。写真や動画はクリップのボタンから添付します。

トラック名も一緒に表示されるので、どの音の話かがすぐ分かります。

画面の各部

  1. 位置つきのメッセージ▶ 小節・拍を押すと、あなたの Logic の再生ヘッドがその位置へ動きます。
  2. トラックどのトラックの話かが一緒に表示されます。
  3. チェック □押すと ✅ が付き、「チェックリスト」タブに入ります（この Mac だけの記録）。
  4. 位置の入力小節・拍、または分・秒を入れて送ります。
  5. 自動・入れたら移動「自動」は Logic で再生ヘッドを止めた位置が自動で入ります。「入れたら移動」は入れた位置へ再生ヘッドを動かします。
  6. リージョン・移動「リージョン」で Logic のトラックとリージョンを添えます。「移動」で送る前に再生ヘッドをその位置へ。
  7. 写真・動画を添付1 通に 10 個まで（写真 50MB・動画 1GB）。入力欄へドラッグしても添付できます。
  8. 送信Return で送信（改行は ⌥Return）。2000 文字まで。
もっと詳しく（アプリ内の使い方）
メッセージを送る
  1. プロジェクトの「メッセージ」タブを開きます。
  2. 下の欄にメッセージを入れて、Return で送ります（改行は ⌥Return）。2000 文字まで送れます。
  3. 写真・動画は、📎 ボタンで選ぶか、入力欄へドラッグします。1 通に 10 個まで、写真は 50 MB、動画は 1 GB までです。添付があれば、本文は空でも送れます。

「閲覧のみ」のメンバーは、写真・動画を送れません（文字は送れます）。

位置を付ける
  1. 入力欄の上の「小節」「拍」（または「分」「秒」）に、位置を入れます。小節は 1〜9999、拍は 1〜64、分は 0〜1439、秒は 0〜59 です。
  2. 「自動」をオンにすると、Logic で再生ヘッドを止めたとき、その位置が自動で入ります。
  3. 「リージョン」を押すと、Logic のトラックとリージョンを選んで添えられます。
  4. 「移動」を押すと、送る前に、Logic の再生ヘッドがその位置へ動きます。

受け取った位置つきの行をクリックすると、あなたの Logic の再生ヘッドがその位置へ動きます（アクセシビリティの許可が必要です）。

05

チェックリストで、直す所を確認

  1. メンバーが書いたメッセージの右にあるチェックを入れると、「チェックリスト」に集まります。
  2. 直したら「実行済みにする」を押すと、下の「実行済み」へ移ります。
  3. チェックした日時が残るので、確認漏れを防げます。

「チェックリストに戻す」で、いつでも元に戻せます。

画面の各部

  1. チェックリストメッセージで ✅ を付けたものが並びます（この Mac だけの記録で、相手には見えません）。
  2. 実行済みにするやり終えたら押すと「実行済み」へ移ります。
  3. チェックした項目元のメッセージ（位置・トラック・本文）。位置を押すと Logic がその位置へ動きます。
  4. チェックした日時いつチェックしたかが残ります。
  5. 実行済み終えた項目。「チェックリストに戻す」で戻せます。
もっと詳しく（アプリ内の使い方）
チェックリスト（自分だけのリスト）
  1. メッセージの行の右上の □ を押すと、✅が付いて、「チェックリスト」タブに入ります。もう一度押すと外れます。
  2. 「チェックリスト」タブで、やったことは「実行済みにする」で「実行済み」へ移します。「チェックリストに戻す」で戻せます。

メッセージのチェックリストは、この Mac だけの記録で、相手には見えません（共有メモのチェックは、メンバー全員に見えます）。

チェックリストと実行済みの意味
  • 「✅（チェックリスト）」: あとでやることの印です。メッセージの右上の □ を押すと ✅ が付き、「チェックリスト」タブに入ります。もう一度押すと外れます。
  • 「実行済み」: やり終えたら、「チェックリスト」タブで「実行済みにする」を押します。同じタブの「実行済み」に移ります。「チェックリストに戻す」で戻せます。
  • 見えるのは自分だけ: メッセージのチェックリストは、この Mac だけの記録で、相手には見えません（共有メモのチェックは、メンバー全員に見えます）。
06

共有メモを、リアルタイムで共有

  1. 「共有メモ」タブでは、位置つきのメモがリアルタイムで共有されます（画面右上に「リアルタイム共有中」と表示）。
  2. 下の欄に位置とメモを入れて「追加」。曲のテンポ（BPM・拍子）も表示されます。
  3. 「すべて／未完了／完了／チェックリスト／実行済み」で絞り込み、「移動」で再生ヘッドをその位置へ。直したら「完了」。

位置は、小節・拍でも分・秒でも指定できます。

画面の各部

  1. リアルタイム共有中メモはメンバー全員に数秒で届きます。入力中の人の名前も出ます。
  2. テンポ位置の換算に使うテンポと拍子。押して変えられます。
  3. 絞り込みすべて・未完了・完了・チェックリスト・実行済み。
  4. 番号と位置位置の順の番号・小節と拍・書いた人。
  5. ✅ と時刻✅ を押すとメンバー全員のチェックリストに入ります。書いた時刻と更新時刻。
  6. 移動・チェックリストに戻す「移動」で Logic の再生ヘッドがその位置へ。✅ のメモは「実行済みにする」「チェックリストに戻す」。
  7. 完了用事が済んだ印（全員に見えます）。「再開」で戻せます。
  8. 位置の入力小節・拍か分・秒。空なら 1 小節 1 拍に書かれます。
  9. メモを書く内容を入れて「追加」（⌘Return）。
もっと詳しく（アプリ内の使い方）
メモを書く
  1. プロジェクトの「共有メモ」タブを開きます。
  2. 位置（小節・拍）を入れて、「気になったところをメモ…」に内容を入れ、「追加」（⌘Return）を押します。位置が空のときは、1 小節 1 拍に書かれます。
  3. メモは、メンバー全員に、数秒で表示されます。入力中の人の名前も表示されます。
メモの操作
  • 「移動」を押すと、Logic の再生ヘッドがその位置へ動きます。
  • 「完了」で完了にして、「再開」で戻します。「未完了」「完了」で絞り込めます。
  • ✅（メモの右上）を押すと、メンバー全員のチェックリストに入ります。「チェックリスト」で絞り込み、「実行済みにする」で「実行済み」へ移します。「チェックリストに戻す」で戻せます。
  • ゴミ箱は、自分が書いたメモだけ削除できます（履歴には残ります）。

共有メモのチェックは、メンバー全員に共有されます。メッセージのチェックリスト（自分だけ）とは別のものです。

完了・チェックリスト・実行済みの違い
  • 「完了」: そのメモの用事が済んだ印です。メンバー全員に見えます。「再開」で未完了に戻せます。
  • 「チェックリスト」: あとでやることの印です。メモの右上の □ を押すと ✅ が付き、メンバー全員のチェックリストに入ります。もう一度押すと外れます。
  • 「実行済み」: ✅ を付けたメモをやり終えたら、「実行済みにする」を押します。間違えたら「チェックリストに戻す」で戻せます。
  • 絞り込み: 「未完了」は完了していないもの、「完了」は完了したもの、「チェックリスト」は ✅ が付いて未実行のもの、「実行済み」は ✅ が付いて実行済みのものです。

✅ が付いたメモでは、ボタンの名前が「実行済みにする」「チェックリストに戻す」に変わります（✅ が無いメモでは「完了」「再開」）。これらはメンバー全員に共有されます。

同時に編集したとき

同じメモが同時に編集されたときは、「相手の版」と「あなたの版」が表示されます。「相手の版を採用」か「あなたの版を採用」を選んでください。

テンポの設定

位置の換算に使うテンポと拍子は、画面右上の「120 BPM 4/4」のようなボタンで変えられます（一定のテンポが前提です）。テンポが途中で変わる曲では、表示される位置がずれることがあります。

07

音を渡す・受け取る（やり取り）

  1. 「やり取り」タブに、送った音・受け取った音が並びます。「すべて／送った／受け取った」で絞り込めます。
  2. Logic のリージョンを常駐パネルへドラッグすると、メンバーに音を送れます。
  3. 自動で録音位置に置く場合は、macOS のアクセシビリティで SYNCRA の許可が必要です（最初に一度だけ。「許可する」を押します）。

受け取った音は、そのまま自分の曲に置けます。

画面の各部

  1. 絞り込みすべて／送った／受け取った。新しい順に並びます。
  2. 更新最新の一覧を読み込みます。
  3. アクセシビリティの許可受け取った音を Logic の録音位置に自動で置くため、最初に一度だけ許可します。
  4. やり取りの一覧▶ で試聴、「復元」で録音フォルダへ置き、「Logic に置く」で録音された位置に新しいトラックとして置きます。
もっと詳しく（アプリ内の使い方）
「やり取り」タブ
  1. プロジェクトの「やり取り」タブを開きます。送った音・受け取った音が、新しい順に並びます（「すべて」「送った」「受け取った」で絞り込めます）。
  2. 行の左の ▶ で試聴します。初回はクラウドから取得し、内容を確認してから鳴らします。
  3. 「復元」を押すと、その Logic プロジェクトの録音フォルダ（Audio Files）に音が置かれます。既存のファイルは上書きされません。
  4. 復元したら「Logic に置く」を押すか、行をダブルクリックします。Logic に新しいトラックが作られ、録音された位置に置かれます。
  5. 置けたら、行の右端の○が✓（実行済み）になります。✓ は、あなたの Mac だけの記録で、相手には見えません。
アクセシビリティの許可（最初に一度だけ）
  1. Logic を操作するには、macOS の「アクセシビリティ」で SYNCRA の許可が必要です。
  2. 画面に「許可する」ボタンが出たら押して、macOS の指示に従ってください。
うまくいかないとき
  • 「自分の曲に置く」が使えないときは、「更新履歴」で版を確認して、もう一度試してください。
  • 新しい版が届いたのに自動で切り替わらないときは、常駐パネルの「受け取って Logic で開く」を押してください。
08

更新履歴と自動同期

  1. 「更新履歴」タブでは、プロジェクトの更新を確認できます。
  2. 自動同期がオンの間は、Logic で保存するたびに、変わった部分だけがメンバーへ送られます。メンバーの更新も自動で受け取ります。
  3. メンバーを招待すると、最初にプロジェクト全体が送られます。「更新」で最新の状態を確認できます。

毎回プロジェクト全体を送り直す必要はありません。

画面の各部

  1. 自動同期の状態オンの間は、Logic で保存すると変わった部分だけを送り、メンバーの更新を自動で受け取ります。
  2. 更新最新の版を読み込みます（20 秒ごとにも自動で更新）。
  3. 版の一覧自動同期でできた版（r1、r2…）が並びます。「確認」で、その版で変わった所へ Logic で移動します。
もっと詳しく（アプリ内の使い方）
「更新履歴」タブ
  • 自動同期でできた版（r1、r2…）が、新しい順に並びます。20 秒ごとに自動で更新されます。
  • 「確認」を押すと、Logic でその曲を開き、その版で更新された音のリージョンを選んで、再生ヘッドを動かします。
  • 未確認の版が多いときは、「すべて確認済みにする」で、一括で確認済みにできます。
  • メンバーの音の行の「自分の曲に置く」は、その音を、あなたの最新の曲の録音された位置に、新しいトラックとして置きます。置いたあとは、保存（⌘S）すると送られます。
「更新履歴」と「履歴」の違い

プロジェクト画面の「更新履歴」は、その曲の版の一覧です。左の一覧の「履歴」は、すべてのプロジェクトのメンバーの行動をまとめた一覧です。

09

「保存して送る」で、送るかどうかを決める

  1. 左の「保存して送る」を開くと、Logic で前面にある曲の変更を、メンバーに送るかどうかを決められます。
  2. Logic の前面に共同プロジェクトの曲がないときは、その旨が表示されます。
  3. 「SMPTE 位置をロックしたリージョンは、確認なしで保存して送る」で、確認の有無を切り替えます。

送る前に確認したい人は、この設定をオフにします。

画面の各部

  1. 保存して送るLogic で前面にある曲の変更を、メンバーに送るかどうかを決めます。
  2. 前面の曲の状態変更なし／保存していない変更あり などを表示。共同プロジェクトの曲が前面に無いときは、その旨が出ます。
  3. SMPTE ロックは確認なしSMPTE 位置をロックしたリージョンは、確認なしで保存して送ります（オフにすると毎回確認）。
もっと詳しく（アプリ内の使い方）
基本の流れ
  • SYNCRA は、共同プロジェクトの曲を 6 秒ごとに見ています。保存の状態が変わって 15 秒ほど落ち着くと、変わった部分だけを送ります。
  • メンバーの新しい版は、20 秒ごとに確認して、自動で受け取ります。
  • 受け取った版は、曲の隣に自動で組み立てられます。Logic で開いていなければすぐ切り替わり、開いているときは閉じたときに切り替わります。
確認のポップアップ
  1. Logic で曲を編集すると、手を止めて 2 秒ほどで、画面の上の中央に「この変更を保存して、メンバーに送りますか？」が出ます（再生中・録音中は出ません）。録音を止めたあとは「録音を保存して、メンバーに送りますか？」です。
  2. 「保存して送る（Y）」を押すと、Logic で保存して送ります。「送らない（N）」を押すと、保存も送信もしません（Logic の作業はそのまま残ります）。
  3. キーでも答えられます。Y か ← で「保存して送る」、N か → で「送らない」です。同じ側のキーを 2 回押すと決まります。途中で反対側を押すと選び直しです。esc はすぐ「送らない」で、Enter とスペースは使えません。

確認は、編集では未保存になった 1 回だけ聞きます。「送らない」を選んだあとは、保存するまで聞き直しません。録音は、1 テイクごとに聞きます。

SMPTE 位置をロックしたリージョンは確認なし

SMPTE 位置をロックしたリージョンがあるときは、確認を出さずに保存して送ります。録音のあとは、ロックするための猶予が 10 秒あります。左の「保存して送る」画面のスイッチ「SMPTE 位置をロックしたリージョンは、確認なしで保存して送る」で、オン／オフを切り替えます（初期はオン）。

左の一覧の「保存して送る」画面
  • Logic で前面にある曲の様子が 1 つだけ大きく出ます。確認待ちのときは、一覧の項目に水色の●が付きます。
  • 「保存していない変更があります」「「送らない」を選んだ変更が残っています」のときは、「いまの変更を保存して送る」で、いつでも送れます。
  • 確認を出したくないときは、「常駐パネル」の「変更・録音のたびに「保存して送るか」を聞く」をオフにします。オフでも、Logic で保存（⌘S）すると送られます。
全体を手動で送る

常駐パネルの「プロジェクト全体を送る」で、Logic で保存した内容をいつでも送れます。前に送ったものと同じファイルは送られません。先に Logic で保存（⌘S）してください。Finder の .logicx を送り先へドラッグしても送れます。

同時に別の人が同じ曲を保存したときは、両方の版が残ります。相手の新しい録音は、あなたの曲に自動で置かれます。置けなかった分は、「更新履歴」の「自分の曲に置く」で取り込めます。

10

プロジェクトのメンバーと権限

  1. 「メンバー」タブで、オーナーと各メンバー（編集可能／閲覧のみ）を確認します。
  2. SYNCRA ID を入れて「探す」、または「QR を読む」で、相手を探して招待できます。一緒に作業したことがある人は、コードなしで招待できます。
  3. 「招待」で権限（編集可能／閲覧のみ）を選び、「招待コードを発行」で招待コードを作れます。

編集可能は、メモの追加や編集、録音の共有ができます。

画面の各部

  1. メンバーの一覧名前・@ID・参加日（1 プロジェクト最大 4 人）。
  2. 役割オーナー・編集可能・閲覧のみ。
  3. SYNCRA ID・QR で招待相手の ID を入れるか QR を読むと、相手に「追加／拒否」が届きます。
  4. 一緒に作業したことがある人コードなしで招待できます。
  5. 権限を選ぶ編集可能（メモの追加・編集、録音の共有）／閲覧のみ。
  6. 招待コードを発行コードを渡して参加してもらいます。
もっと詳しく（アプリ内の使い方）
メンバーを追加する（オーナー）
  1. 「プロジェクト」画面の下の「メンバーを追加」を押します。
  2. 「追加する曲」と「権限」（「編集可能」か「閲覧のみ」）を選びます。
  3. 次の 3 つの方法から選びます。
方法 1: QR コードで追加
  1. 「QR コードで追加」を押します。
  2. 相手の SYNCRA の「アカウント」画面の QR コードを、Mac のカメラで読みます。「画像ファイルから」や「クリップボードの画像から」でも読めます（AirDrop で携帯に保存した QR でも可）。
  3. 相手に「追加／拒否」が届きます。相手が「追加」を押すと、選んだ権限で参加します。
方法 2: 招待コードで追加
  1. 「招待コードを発行」を押します。
  2. 表示されたコードを、「コードをコピー」で相手に送ります。コードは 1 回だけ使えて、有効期間は 7 日です。
  3. 相手がコードを入力すると、「メンバー」タブに「参加の申し込み」が届きます。「追加」を押すと参加が決まります（「拒否」も選べます）。
方法 3: SYNCRA ID で追加
  1. 相手の SYNCRA ID（例: @syncra_1）を欄に入れて「追加」を押します（Return でも可）。
  2. 「友だち」一覧の人は、行の「追加」からも招待できます。
  3. 相手に「追加／拒否」が届きます。
招待された人の操作
  1. 「プロジェクト」画面に「「◯◯」に招待されています」が出ます。「追加」を押すと参加します（「拒否」も選べます）。通知の「追加」「拒否」ボタンでも答えられます。
  2. 招待コードをもらったときは、「受け取った招待コードで参加…」を開き、32 桁のコードを入力して「参加する」を押します（ハイフンや空白はあってもなくても構いません）。
  3. 参加したら、自動で曲が「ミュージック/SYNCRA」に受け取られ、紐づきます。自動で決められないときは、「手元の曲を選ぶ…」で選んでください。
権限の違い
  • 「オーナー」: 招待・メンバー管理・編集ができます。
  • 「編集可能」: メモの追加や編集、録音の共有ができます。
  • 「閲覧のみ」: メモと状態を見ることだけができます。

招待とメンバーの管理ができるのは、オーナーだけです。

友だちから外す

  3. 名前は、欄に入れて「保存」を押します。
  4. SYNCRA ID は、欄に入れると、使えるかどうかが自動で表示されます。使えるなら、「変更」を押します。

SYNCRA ID は、英小文字・数字・_ の 3〜20 文字（先頭は英小文字か数字）です。変更は 1 か月に 1 回までで、ほかの人が使っている ID には変えられません。

QR コードの使い道

「ID をコピー」「QR 画像をコピー」「QR を保存…」「QR を AirDrop で送る」「共有…」で、ID や QR を相手に渡せます。

iPhone とリンクする
  1. 「iPhone とリンク」の「QR コードを表示」を押します。
  2. iPhone の SYNCRA で「Mac の QR コードを読む」を押し、この QR コードを読みます。パスワードなしで同じアカウントにサインインできます。
  3. iPhone で SYNCRA ID を入れて申し込んだときは、Mac に「iPhone から SYNCRA へのサインインを求められています」と、端末名と番号が出ます。iPhone の画面にも同じ番号が出ているときだけ、「許可する」を押してください。

QR コードは、他の人に見せないでください。読んだ iPhone は、あなたのアカウントでサインインします。有効期限は短く、1 回だけ使えます。

端末の管理とログアウト
  • 「リンクしている端末」の「一覧から外す」で、その iPhone を外せます。
  • なくした iPhone があるときは、「この Mac 以外の端末をすべてサインアウト…」を使います。
  • 「この Mac でログアウト…」を選んでも、登録したプロジェクトと手元のファイルは消えません。

よくある質問

よくある質問

SYNCRA はどんなアプリですか？

Mac の Logic Pro で作っている曲を、iPhone・iPad で聴きながら、メンバーと確認・修正できる共同制作アプリです。

iPhone・iPad だけで使えますか？

音を聴くには、Mac 版 SYNCRA（macOS 14 以降）と Logic Pro が必要です。iPhone・iPad だけでは音は聴けません。

iPhone・iPad で音が聴こえません

Logic の Stereo Out に「SYNCRA Monitor」を挿してあるか確認してください。Mac と iPhone・iPad を同じ Wi-Fi につなぎ、iPhone・iPad の「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で SYNCRA をオンにしてください。

無料体験は自動で有料になりますか？

なりません。7 日間・1 人 1 回・保存 1GB までです。有料プランを契約しなかった場合、体験中のクラウド上の共同プロジェクトは終了から 30 日後に削除します。

解約・返金は？

解約すると次回以降の更新の課金が止まります。iPhone・iPad の App 内課金は「設定」→ 自分の名前 →「サブスクリプション」から。返金は返金の方針をご覧ください。

アカウントを削除したい

アプリの「設定」→「アカウントを削除」から行えます。
