Logic Pro × iPhone・iPad

Logic の曲を、
みんなで仕上げる。

Mac の Logic Pro の音を、同じ Wi-Fi の iPhone・iPad でそのまま聴ける。ループ・ソロ・位置つきの共有メモで、確認と修正の相談がその場で進みます。

SYNCRA は、Mac の Logic Pro と iPhone・iPad をつなぐ、音楽の共同制作アプリです。

できること

曲の確認に、新しい流れを。

Mac の前に集まらなくても、同じ音を聴きながら、同じ所を指して話せる。修正の相談が、その場で進みます。

Logic の音を iPhone・iPad で聴く

Logic Pro に挿す「SYNCRA Monitor」から、同じ Wi-Fi の iPhone・iPad へ、圧縮しない 32bit float で音を送ります。曲全体の波形を見ながら聴きたい所へ移動。10 秒の前後移動、LIVE への復帰もワンタップ。ステレオ／モノ／左／右の切り替えと、遅延の表示に対応。

ループを 3 つ覚える

波形をなぞるだけでループの範囲を決められます。A・B・C に覚えて、押すだけで呼び出し。Logic のサイクルと連動するので、Mac を触らずに繰り返し聴けます。

トラックをソロで聴く

iPhone・iPad からトラックのソロを切り替え。ソロ中のトラックは色分けした波形で重ねて表示します。

気になった所に、その場で共有メモ

聴いている位置に共有メモをワンタップで追加。小節・拍でも、分・秒でも指定できます。メモやメッセージの位置を押すと、Mac の Logic の再生ヘッドがそこへ移動します。

メンバーと相談

プロジェクトのメンバーとメッセージ・共有メモでやり取り。写真や動画も添付できます。共有メモはチェックリストにでき、「直す所」の確認漏れを防げます。メンバーのオンライン・再生位置もひと目で分かります。

7 か国語に対応

日本語・英語・ドイツ語・フランス語・スペイン語・韓国語・ポルトガル語（ブラジル）。Logic Pro の各言語の用語に合わせています。

使い方

実際の画面で、すべての機能の使い方

上の流れる帯の項目を押しても、その使い方に飛べます。

01

Logic の音を iPhone・iPad で聴く

  1. Mac の Logic Pro で、Stereo Out に「SYNCRA Monitor」を挿します。
  2. iPhone・iPad の SYNCRA を開き、同じ Wi-Fi の Mac を選びます（初回は QR コードか 6 桁のコード）。
  3. 画面上の「LIVE」が点いたら、Logic の音がそのまま聴こえます。

圧縮しない 32bit float で届きます。ステレオ／モノ／左／右の切り替えと、出力先・遅延の表示は画面下の設定から。

02

曲全体の波形で、好きな位置へ

  1. 曲全体の波形が表示されます。聴きたい所をなぞると、Mac の Logic の再生ヘッドがそこへ動きます。
  2. 小節・拍と分・秒が表示されるので、場所を伝えやすくなります。
  3. 「LIVE」を押すと、Logic が今鳴らしている位置に戻ります。

Mac を触らなくても、iPhone・iPad から曲の中を自由に行き来できます。

03

ループを A・B・C に 3 つ覚える

  1. 波形をなぞって、繰り返したい範囲を決めます。
  2. 決めた範囲を A・B・C のボタンに覚えておきます。押すだけで呼び出せます。
  3. 「ループ」をオンにすると、Logic のサイクルと連動して繰り返し再生します。

気になる所を何度でも。サビ前・ブレイク・コーラスなど、3 か所を切り替えながら確認できます。

04

Mac の Logic を iPhone・iPad から操作

  1. 真ん中の大きなボタンで再生・停止。
  2. 左右の「10」ボタンで、10 秒戻す・10 秒送る。
  3. 再生の位置は波形と小節・拍の表示で確認できます。

演奏しながら、楽器を置いたまま手元で操作できます。

05

トラックをソロで色分けして聴く

  1. 「トラックソロ」を開き、聴きたいトラック（例：Drums、Lead）を選びます。
  2. ソロ中のトラックは、色分けした波形で重ねて表示されます。
  3. 「すべて解除」で元に戻ります。

どの音を聴いているかがひと目で分かるので、「このトラックのここ」が伝えやすくなります。

06

気になった所に、その場で共有メモ

  1. 聴きながら、気になった所で「この位置にメモ」を押します。
  2. 内容を書いて送ると、曲の位置（小節・拍または分・秒）つきでメンバーに届きます。
  3. メモを押すと、Mac の Logic の再生ヘッドがその位置へ移動します。

「イントロの Pad、左右にもう少し広げて」のように、場所つきで残せます。

07

共有メモで、直す所をチェック

  1. 「共有メモ」タブを開くと、メンバーからのメモが位置つきで並びます。
  2. 「未完了／完了／チェックリスト／実行済み」で絞り込めます。
  3. 直したら「完了」にチェック。誰がいつ確認したかも残ります。

直す所の確認漏れを防ぎます。進み具合もひと目で分かります。

08

メンバーとメッセージで相談

  1. 「メッセージ」タブで、プロジェクトのメンバーとやり取りします。
  2. 小節・拍・トラックの位置をつけて送れます。写真や動画の添付もできます。
  3. 位置つきのメッセージを押すと、Logic の再生ヘッドがそこへ移動します。

通報とブロックは、メッセージの長押し（Mac では右クリック）から行えます。

09

メンバーの今がひと目でわかる

  1. 「メンバー」タブで、誰がオンラインかを確認できます。
  2. 「録音中」「編集中」などの状態と、再生位置が表示されます。
  3. 更新履歴（r1、r2…）で、誰がいつプロジェクトを更新したかを確認できます。

離れていても、同じプロジェクトの今が共有できます。

10

7 か国語に対応

  1. 初回起動時に言語を選びます（日本語・英語・ドイツ語・フランス語・スペイン語・韓国語・ポルトガル語）。
  2. あとから「設定」の「言語」で変えられます。
  3. Logic Pro の各言語の用語（トラック、リージョン、再生ヘッドなど）に合わせています。

はじめかた

Mac に入れて、Logic に挿して、iPhone・iPad とつなぐだけ。

難しい設定はいりません。

1
Mac 版 SYNCRA を入れる

ダウンロードした ZIP を開き、SYNCRA を「アプリケーション」フォルダへ移します。Apple の公証済みなので、そのまま開けます。

2
アカウントを作る

Apple でサインイン、またはメールで登録します。7 日間の無料体験があり、自動で有料には切り替わりません。

3
Logic に「SYNCRA Monitor」を挿す

Logic Pro の Stereo Out にプラグインを挿すと、Logic の音が iPhone・iPad へ送られます。

4
iPhone・iPad とペアリング

iPhone・iPad の SYNCRA で、Mac に表示される QR コードを読むか、6 桁のコードを入れます。Mac と同じ Wi-Fi で使います。

5
聴く・確かめる・相談する

波形で移動し、ループとソロで確かめ、気になった所に共有メモ。メンバーと相談しながら仕上げます。

よくある質問

よくある質問

SYNCRA はどんなアプリですか？

Mac の Logic Pro で作っている曲を、iPhone・iPad で聴きながら、メンバーと確認・修正できる共同制作アプリです。

iPhone・iPad だけで使えますか？

音を聴くには、Mac 版 SYNCRA（macOS 14 以降）と Logic Pro が必要です。iPhone・iPad だけでは音は聴けません。

iPhone・iPad で音が聴こえません

Logic の Stereo Out に「SYNCRA Monitor」を挿してあるか確認してください。Mac と iPhone・iPad を同じ Wi-Fi につなぎ、iPhone・iPad の「設定」→「プライバシーとセキュリティ」→「ローカルネットワーク」で SYNCRA をオンにしてください。

無料体験は自動で有料になりますか？

なりません。7 日間・1 人 1 回・保存 1GB までです。有料プランを契約しなかった場合、体験中のクラウド上の共同プロジェクトは終了から 30 日後に削除します。

解約・返金は？

解約すると次回以降の更新の課金が止まります。iPhone・iPad の App 内課金は「設定」→ 自分の名前 →「サブスクリプション」から。返金は返金の方針をご覧ください。

アカウントを削除したい

アプリの「設定」→「アカウントを削除」から行えます。
